# 현장 실증 순서표

- 목적: 실제 카메라, LTE, 밖에서 두 사람이 만나는 흐름으로 선별 전달 한 사이클(D036)을 끝까지 돌린다. 진행 순서는 촬영 10분 → 작가가 사진을 폰으로 옮겨 5~8장 고르기 → 공개 → 고객 구매·저장이다.
  - 2026-11-21 전환 전의 실시간 FTP 순서표는 보관 태그 `archive/live-ftp-v1`에 있다(`docs/archive/live-ftp.md`).
- 목표 시간: 촬영 종료 뒤 5~15분 안 공개.
- 서버 시각(확정, 작가 앱 받음, 시작, 종료, 사진 업로드, 공개, 찜, 구매, 고객 저장)은 자동으로 남는다. 사람은 결과(○ 됨, △ 늦거나 일부, × 안 됨)와 눈으로 본 것만 적는다.
- 작가 앱 티켓 폴더의 `events.csv`에 종료·업로드·공개 시각이 따로 남는다.
- 끝나면 맥에서 백엔드 저장소(웹 프로젝트)의 `firebase/scripts/field_report_dev.py`로 시각표를 뽑아 맨 아래 "결과"에 붙인다.

## 준비물

- 카메라: a7C II(실증한 기종), a7 III. 배터리, 메모리 카드. 카드 리더(선택).
- 작가 폰(작가 앱, 소니 Creators' App, 선택으로 라이트룸), 고객 폰(고객 앱, LTE). 두 사람. 작가 폰용 보조 배터리(선택).
- 두 앱 모두 2b9ef1d 이후 빌드. sbsn-dev가 선별 규칙으로 전환된 뒤에만 된다(D043).

## 출발 전(실내)

| # | 할 일 | 확인 |
|---|---|---|
| P1 | 카메라 파일 형식은 JPEG(또는 HEIF). RAW만 찍으면 앱이 받지 않는다(RAW+JPEG면 JPEG가 온다) | |
| P2 | 카메라 시계를 폰 시계에 1분 안으로 맞춘다(촬영 시간대 밖 경고가 시계 기준이다). 위치 연동을 켜면 사진에 위치가 들어가고 구매한 고객에게 그대로 전달된다(D037) | |
| P3 | Creators' App으로 카메라와 작가 폰을 연결해 두고, 사진을 "원본" 크기로 가져오는지 본다(축소 설정은 끈다) | |
| P4 | 작가 폰: 저전력 모드 끔, 십분스냅 작가 알림 허용 | |
| P5 | 고객 폰: 와이파이 끄고 LTE. 위치 "앱을 사용하는 동안" 허용. 사진 추가 권한은 첫 구매 때 허용 | |

## 실내 리허설(두 폰, 약 20분)

| # | 할 일 | 기대 | 결과 | 메모 |
|---|---|---|---|---|
| R1 | 작가 "촬영 가능" 켬 → 고객 지도에서 작가 선택 → "이 작가와 촬영하기" → 확정 → 시작 전에 고객 "취소" | 작가 폰에 매칭 알림. 취소 뒤 작가 앱은 대기로 돌아오고, 고객이 "지도로 돌아가기"를 누르면 작가가 다시 보인다 | | |
| R2 | 다시 확정 → 고객·작가 "촬영 시작"(고객은 "결제 없이 계속") → 6장 촬영 → 작가 "촬영 종료" | 양쪽 10분 표시. 종료하면 작가 앱은 "사진 고르기", 고객은 "작가가 사진을 고르는 중" | | |
| R3 | 작가: Creators' App으로 6장 가져오기 → 작가 앱 "사진 앱에서 추가"로 6장 → "고객에게 공개" | 고르는 즉시 칸마다 올라감 표시. 다 올라가면 공개. 고객 폰에 공개 알림, 갤러리 6장(작가가 정한 순서). 공개 전에는 고객에게 사진이 없다 | | 종료 → 공개 분: |
| R4 | 고객: 1장 구매 | 바로 사진 앱에 저장. 작가 폰에 구매 알림 | | |

## 끝난 뒤

1. 맥에서 시각표를 뽑는다(백엔드 저장소(웹 프로젝트) 루트에서, 토큰은 출력하지 않는다).
   ```
   export SBSN_ADMIN_TOKEN="$(gcloud auth application-default print-access-token)"
   python3 -I firebase/scripts/field_report_dev.py latest <작가 uid>
   ```
   작가 uid는 작가 앱 마이 탭 "개발"의 작가 ID다. 안드로이드 교차 시험도 sbsn-dev에 티켓을 만들기 때문에 uid 없이 `latest`만 쓰면 다른 티켓을 고를 수 있다.
2. 고객 폰 사진 앱에서 저장본 정보를 열어 JPEG인지 보고, 카카오톡으로 한 장 보내 열리는지 본다.
3. 문제가 있었던 단계는 작가 앱 티켓 폴더(`Application Support/Tickets/<티켓>/`)의 `session-log.txt`(가져오기·렌더·업로드·공개 기록)와 `events.csv`를 맥에 연결해 꺼내 본다. 공개가 끝나면 로컬 사본을 지우므로 문제가 있으면 공개 전에 꺼낸다.
4. 작가 폰 배터리 곡선: 작가 앱 `Application Support/device-log.csv`(5분마다 배터리·충전·저전력·발열·앱 상태·촬영 단계)를 맥에 연결해 꺼낸다. 12번의 손 기록과 맞춰 본다.
5. 선택기에서 위치를 끄면 다른 메타데이터도 바뀌는지(I008 보충, D037). 위치 연동으로 찍은 a7C II JPEG 1장으로 본다.
   - 작가 앱 마이 → 개발 → "메타데이터 경로 시험" → "선택기 .current"로 그 사진을 고른다. 선택기 아래 "선택된 항목 표시 → 옵션 → 위치"는 켠 채로 둔다. 받은 파일(`Documents/MetaProbe/current/0-<이름>`)을 맥으로 꺼낸다.
   - 같은 사진을 "옵션 → 위치"를 끄고 다시 고른다(같은 이름에 덮어쓴다). 다시 꺼낸다.
   - 원본은 "파일에서(fileImporter)" 경로(`MetaProbe/files/`)나 카드 리더로 받는다.
   - 기대: 위치 켬은 원본과 바이트가 같다. 위치 끔은 GPS IFD만 빠지고 MakerNote·XMP·IPTC가 바이트째 같다(iOS 27 시뮬레이터 합성 사진에서는 GPS IFD가 빠지고 IPTC 크기가 바뀌었다, 설계 문서 4.3.1). GPS 말고 다른 항목이 바뀌면 총괄에 보고한다.
   - 좌표 값은 기록하지 않는다. 끝나면 "받은 파일 지우기"로 지운다.
